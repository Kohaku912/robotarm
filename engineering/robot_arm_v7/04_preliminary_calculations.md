# 主要計算（CAD前）

> V8 J2改訂: 直結案は廃止し、16T/32T・3GT×9・135 mm・効率0.90の2:1ベルトを採用した。出力停止トルクは`0.922×2×0.90=1.6596 N m`。小プーリー巻付151.032°、噛合6.713歯、停止時接線力120.69 N。最終質量による再計算は`V8_final_calculations.md`を正とする。

## 公式部品値

- MG996R: 4.8 V停止トルク9.4 kgf cm = 0.922 N m、質量55 g。
- MG90S: 4.8 V停止トルク1.8 kgf cm = 0.177 N m、質量13.4 g。
- F695ZZ: Cr=1190 N、C0r=430 N、5x13x4 mm、フランジ15x1 mm。
- PA12-CF10: 密度1.06 g/cm3、湿潤Z引張強度42.1 MPa。設計許容20 MPa。

## LC-01 水平静荷重

肩軸まわりの暫定質量モデルから、構造・サーボ・締結品の重力モーメントを0.258 N m、50 gペイロードを0.141 N mと見積もる。

`T_J2_static = 0.258 + 0.050 * 9.80665 * 0.288 = 0.399 N m`

MG996R停止トルクに対する余裕率は`0.922 / 0.399 = 2.31`。

## LC-02 最大加速度120 deg/s2

肩軸まわり暫定慣性`I = 0.0090 kg m2`、`alpha = 2.094 rad/s2`。

`T_inertia = I * alpha = 0.019 N m`

`T_J2_accel = 0.399 + 0.019 = 0.418 N m`、停止トルク比45.3%。

## LC-03 急停止600 deg/s2

`alpha_stop = 10.472 rad/s2`

`T_stop = 0.399 + 0.0090 * 10.472 = 0.493 N m`

停止トルク安全率`0.922 / 0.493 = 1.87`。暫定サーボ基準1.5には合格するが、熱連続定格が公開されていないため、30秒保持温度試験を必須とする。

## J3概算

前腕以遠の重力トルク約0.172 N m。急停止を含めても0.23 N m未満の見込みで、MG996R停止トルク安全率は4以上。

## 5 mm鋼軸

J2最大トルク0.493 N mを中実丸軸へ入力したとき、

`tau = 16T / (pi*d^3) = 20.1 MPa`

SUJ2相当材の保守的許容せん断145 MPaに対し安全率7.2。最終CADの軸受間隔で曲げ合成応力を再計算する。

## 軸受

全遠位質量を0.25 kg、急停止等価3gとしても荷重は7.4 N。F695ZZ静定格430 Nに対し安全率58で、要求1.5を上回る。実際はモーメントを軸受間隔で受けるため、最終反力をCAD寸法から再計算する。

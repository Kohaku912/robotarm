# MG996Rホーンレス直結16Tプーリー試作

支給された `MG996R_SERVO.step` の出力スプラインB-repを雌型として使用した、J2用3GT 16T・幅9 mmの試作部品。ホーンは使用せず、スプラインでトルクを伝え、中央M3ねじで軸方向を保持する。

## 重要

- 状態は `PROTOTYPE_NOT_LOAD_APPROVED`。主設計の支持入力軸とF685ZZ×2を省略するため、約120.7 Nのベルト接線力と張力がサーボ出力軸受へ戻る。
- クーポンの角欠き側が0.05 mm、中央が0.10 mm、反対端が0.15 mm。試験は反対端の0.15、中央0.10、角欠き側0.05 mmの順で、電源を切ったサーボへ手で試す。工具で押し込まない。
- 中央ねじはM3×8またはM3×10、頭径6 mm・高さ2 mmを想定。実サーボの中央雌ねじがM3であること、底付きしないことを実測する。
- 0.10 mm版を標準STLにした。緩い場合でも接着剤で補修せず、クリアランス値を変更して再生成する。

## 印刷条件

- Fiberon PA12-CF10、乾燥条件を材料仕様に従って記録
- 軸方向Z、0.15 mm層、8周、スプライン周囲100%相当
- 積層後にバリだけ除去し、スプライン歯面をドリルやリーマで加工しない

## 合格手順

1. クーポンが手圧で奥まで入り、逆さにして自然落下せず、抜去後にサーボ歯面を傷つけない。
2. 中央ねじを低トルクで締め、プーリー端面の振れを測る。
3. 無負荷で低速往復し、割れ、偏心、異音がない。
4. ベルトを掛ける前に30秒保持試験を行う。
5. ベルト試験では軸受温度、ガタ、歯飛びを確認する。合格するまでロボットアームへ採用しない。

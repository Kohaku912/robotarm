# Robot Arm Body Prototype V1

5軸ロボットアーム本体の印刷データです。公差クーポンは含みません。

## 確定公差
- F695ZZ座: 13.05 mm
- M5密着穴: 5.00 mm
- M5通し穴: 5.30 mm
- J1歯車中心距離: 54.55 mm
- J4歯車中心距離: 19.35 mm

`BODY_PLATE_01.stl`から順に印刷できます。各部品は4 mm以上の外接間隔で完全に分離され、接続線・外周フレーム・クーポンはありません。

最初は無通電で全軸を手回しし、F695ZZ外輪押さえ、M5軸カラー、歯車噛み合いを確認してください。
